# Emergency-Response-Network
A Python-based Emergency Response Network that uses Graph Theory and Dijkstra's Shortest Path Algorithm to optimize emergency vehicle routing. Built with NetworkX, Matplotlib, and Google Maps API for efficient route planning and visualization.

# 🚑 Emergency Response Network

> A Python-based Emergency Response Network that uses **Graph Theory** and **Dijkstra's Shortest Path Algorithm** to identify the shortest and fastest route for emergency vehicles.

## 📖 Overview

Emergency situations require quick and efficient routing of ambulances, fire trucks, and police vehicles. This project models an emergency transportation network using **Graph Theory** and computes the shortest path between locations using **Dijkstra's Algorithm**.

The project also visualizes the network using **Matplotlib** and can be extended with **Google Maps API** for real-world route optimization.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YourUsername/Emergency-Response-Network.git
```

Move into the project folder:

```bash
cd Emergency-Response-Network
```

Install dependencies:

```bash
pip install -r requirements.txt
```

```bash

```
